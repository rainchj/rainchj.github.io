시그널 신호

이 프로그램은 과매도·과매수 임계값뿐 아니라 MACD 교차·추세 강도, BB 패턴, SMA 배열, 복합 지표 조건을 모두 자동으로 분류해 시그널 신호를 생성합니다.

  • 과매수/과매도: BB, RSI, Slow STC, Z-score의 개별지표 or 복합지표
  • BB=무릎차트: BB 상하단밴드선이 동시 하락하다 하단밴드선이 수평되는 시점
  • BB=갈비뼈차트: BB 상하단밴드선이 동시 상승하다 상단밴드선이 수평되는 시점
  • BB=상승차트: BB 상하단밴드선이 모두 상승하는 시점
  • BB=하락차트: BB 상하단밴드선이 모두 하락하는 시점
  • BB=급락주의: 상하단 밴드폭이 벌어지면서 종가가 하단밴드선을 타고 내려오는 시점
  • BB=급등주의: 상하단 밴드폭이 벌어지면서 종가가 상단밴드선을 타고 올라가는 시점
  • SMA=정배열: SMA단기 > SMA중기 > SMA장기
  • SMA=역배열: SMA단기 < SMA중기 < SMA장기
  • MACD=골든크로스: MACD선이 Signal선을 밑에서 위로 교차하는 시점
  • MACD=데드크로스: MACD선이 Signal선을 위에서 아래로 교차하는 시점
  • MACD=강상승추세: MACD > 0 & 상승 + 히스토그램 > 0 & 상승
  • MACD=강하락추세: MACD < 0 & 하락 + 히스토그램 < 0 & 하락
  • MACD=상승추세약화: MACD > 0 & 하락 + 히스토그램 > 0 & 하락
  • MACD=하락추세약화: MACD < 0 & 상승 + 히스토그램 < 0 & 상승
  • 복합=매수신호1: BB 하단밴드 기울기 상승 + MACD Histogram 2일 연속 증가 + RSI < 40 & 상승 + STC < 20 & 상승
과매도 · 과매수 발생 횟수 및 기간별 반전 확률
  • 과매도 기준: BB 하단 이탈, RSI ≤ 30, Slow STC ≤ 20, Z-score ≤ -2.0
  • 과매수 기준: BB 상단 돌파, RSI ≥ 70, Slow STC ≥ 80, Z-score ≥ +2.0
  • 기간별 반전 확률: 신호 발생 후 1일, 2일, 3일, 5일, 10일, 20일 경과 시점의 상승/하락 반전 횟수 및 확률 집계
  • 중복 처리: 첫날 방식 & 전부 방식 동시 제공
증감률 통계 분석
  • 조건 추출: 전일대비 증감률(예: -2.29%) 이하로 하락했던 과거 일수 추출 (총 분석 일수 대비 빈도)
  • 기간별 상승확률 & 수익률: 발생 후 1일~11일(최대 20일) 후 종가 기준 상승확률, 평균 수익률, Min(최대 낙폭), Max(최대 수익률) 완벽 산출
💡 증감률 분석 출력 예시:
KOSPI 분석결과 (최종일 증감률 -2.29%, 증감률 이하 일수 46일 / 총 314일)
1일후 종가 | 상승확률 57% | 평균 0.17% | Min -8.77% | Max 11.49%
5일후 종가 | 상승확률 60% | 평균 1.46% | Min -22.62% | Max 24.11%
10일후 종가 | 상승확률 71% | 평균 8.85% | Min -14.49% | Max 55.31%

주봉 · 월봉 주봉 · 월봉 분석 (Z-score 기준 익주/익월 상승확률 및 수익률)

단기 노이즈를 배제하고 중기(주봉) 및 장기(월봉) 흐름을 진단하기 위해, 현재 시점의 Z-score 수준을 과거 5년 이상의 데이터와 대조합니다.

주봉 Z-score 분석

주봉 기준 현재 Z-score 값 이하로 진입했던 과거 횟수를 집계하고, 이 경우 다음 주(1주 후)에 상승했던 확률 및 주간 고가·저가·종가 수익률 변동 범위를 분석합니다.

월봉 Z-score 분석

월봉 기준 현재 Z-score 값 이하였던 과거 횟수를 집계하고, 이 경우 다음 달(1개월 후)에 상승했던 확률과 월간 고가·저가 수익률 범위를 정밀 진단합니다.

분기봉 · 년봉 분기봉 · 년봉 분석 (연봉시가3선 지표)

가치투자와 대세 추세 판단에 강력한 연봉시가3선 지표를 산출하여 주가의 초장기 지지/저항선을 분석합니다.

📐 연봉시가3선 공식:
연봉시가3선 = (올해 시작가 × 3 + 작년 시작가 × 2 + 전전년 시작가 × 1) / (1 + 2 + 3)
* 현재 주가가 연봉시가3선 위에 위치하는지 여부를 통해 장기 상승 추세의 견고함을 평가합니다. (참고: 연봉시가3선 분석 가이드)

1

Google AI Studio 접속

구글 계정으로 로그인 후 아래 링크로 이동합니다. 별도의 복잡한 절차 없이 구글 계정으로 즉시 연동됩니다.

→ https://aistudio.google.com
2

API 키 생성

좌측 메뉴에서 「Get API key (API 키)」 클릭 → 우측 상단 「Create API key」 버튼을 클릭하면 키가 즉시 발급됩니다.

🔑 생성된 키는 AIzaSy...로 시작하는 문자열입니다. 복사해 두세요.
3

프로그램 엑셀에 입력

엑셀 프로그램의 API 키 입력 셀에 복사한 키를 붙여넣고, 원하는 Gemini 모델(예: gemini-3.5-flash 또는 gemini-3.7-flash)을 선택합니다.

4

무료 플랜 팁

무료 플랜으로도 충분한 분석이 가능하며, 만약 일일 호출 한도에 도달한 경우 새 프로젝트를 생성하여 추가 키를 발급받거나 gemini-3.5-flash-lite와 같은 경량 모델을 활용하시면 여유롭게 사용할 수 있습니다.

누구나 쉽게 시작하는 4단계 분석 가이드
엑셀을 실행하고 몇 번의 클릭만으로 전문적인 AI 투자 리포트를 얻을 수 있습니다.
1

프로그램 다운로드 및 매크로 허용

상단 다운로드 링크에서 압축 파일을 내려받아 비밀번호로 해제한 후, 엑셀 실행 시 매크로 실행을 허용합니다.

매크로 차단 시 해제 방법: 파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 신뢰할 수 있는 위치에 폴더 추가 후 파일 실행
2

API 키 입력 및 모델 선택

발급받은 Google Gemini 무료 API 키를 엑셀 셀에 입력하고, 원하는 모델(gemini-3.5-flash 등)을 선택합니다.

3

종목 입력 및 지표 생성

시총 100위 자동 입력(코스피/코스닥/ETF/USA) 기능을 이용하거나 개별 티커를 입력하고, 분석 기간을 설정하여 지표 데이터를 자동 산출합니다.

4

AI 분석 리포트 생성 및 확인

[개별종목 매수시점 분석] 또는 [투자유망종목 선정] 버튼을 누르면 AI 분석이 진행되어 브라우저에 완성된 HTML 리포트가 자동으로 열립니다.

* 수작업 분석이 필요할 때는 내 PC > 문서 > 유망종목_오늘날짜 폴더에 자동 생성된 파일들을 Gemini 웹에 직접 첨부하여 사용할 수도 있습니다.

자주 묻는 질문 (FAQ)
시가총액 100위 자동 종목입력 기능은 어떻게 사용하나요? +
프로그램 상단의 시장 선택(코스피, ETF, 코스닥, USA) 후 종목 개수(기본 디폴트 10개 ~ 최대 100위)를 설정하면, 최신 시가총액 상위 종목 리스트가 엑셀 시트에 자동으로 입력되어 간편하게 다종목 일괄 분석을 수행할 수 있습니다.
개별종목 매수시점 분석과 투자유망종목 선정의 차이는 무엇인가요? +
개별종목 매수시점 분석은 단일 종목에 대해 현재 상황, 기술적 지표, 일봉 증감률 통계, 주봉/월봉 Z-score 반등확률, 연봉시가3선을 종합 진단하여 매수 적기인지를 평가합니다.
투자유망종목 선정은 여러 종목을 한꺼번에 스크리닝하여 반등 가능성이 가장 높은 Top 5 유망종목과 리스크가 커서 제외해야 할 종목을 사유와 함께 순위별로 도출합니다.
증감률 분석(전일대비 급락 시 기간별 통계)은 무엇을 의미하나요? +
분석 기준일의 하락률(예: -2.29%)과 같거나 더 큰 폭으로 하락했던 과거 모든 날짜를 추출하여, 그 이후 1일~20일 경과 시점의 상승 확률, 평균 수익률, 최대 낙폭(Min), 최대 수익률(Max)을 통계로 산출한 것입니다. 과거 유사 급락 후 언제 얼마나 반등했는지를 수치로 객관화합니다.
연봉시가3선 분석이란 무엇인가요? +
연봉시가3선은 (올해시가×3 + 작년시가×2 + 전전년시가×1) / 6으로 계산되는 가중 시가 지표로, 장기 투자 및 대세 추세의 강력한 지지/저항선 역할을 합니다. 주가가 이 선 위에 안착해 있는지를 통해 장기적인 안정성을 검증합니다.
프로그램 내 자동 분석 외에 수작업 파일 첨부 분석은 어떻게 하나요? +
프로그램에서 분석 실행 시 내 PC > 문서 > 유망종목_오늘날짜 폴더에 분석용 파일들이 자동 생성됩니다.

• 투자유망종목 선정: 문서 > 유망종목_오늘날짜 (예: 유망종목_260824) 폴더 내 유망종목_USER.csv, 유망종목_컬럼해설.csv를 Google AI Studio 또는 Gemini 웹에 첨부하고 유망종목_질의문장.txt 내용을 질문창에 복사/붙여넣기하여 분석합니다.

• 개별종목 매수시점 분석: 문서 > 유망종목_오늘날짜 > [개별종목폴더] (예: ...\KOSPI) 폴더 내 [종목명].csv, [종목명]_pr.csv, [종목명]_sc.csv, [종목명]_컬럼해설.csv를 첨부하고 [종목명]_질의문장.txt 내용을 질문창에 복사/붙여넣기하여 분석합니다.
Gemini 무료 API 호출 한도가 초과되면 어떻게 하나요? +
Google AI Studio에서 새로운 프로젝트를 생성하여 추가 API 키를 발급받아 교체하거나, 일일 호출 한도가 넉넉한 gemini-3.5-flash-lite 또는 gemini-3.1-flash-lite 모델을 프로그램에서 선택하시면 무료 한도 걱정 없이 원활하게 분석할 수 있습니다.
프로그램 압축 해제 비밀번호는 어떻게 확인하나요? +
본 프로그램은 지인 대상 한정 배포용으로 제공됩니다.
